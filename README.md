# Kandhan Microgreens Android App

Android Studio project starter for Kandhan Microgreens.

Included:
- Home, Products, Cart and Orders screens
- UPI intent using UPI ID `9791538351@cnrb`
- WhatsApp ordering using the configured business number
- Microgreens catalog and cart

Open the project folder in Android Studio, sync Gradle, then build/run on an Android device or emulator.

This is a production-oriented starter, not a completed backend-connected Play Store release. Before publishing, add secure authentication, server-side order storage, payment verification/webhooks, privacy policy, app signing, and Play Console configuration.
